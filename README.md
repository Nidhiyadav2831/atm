# ATM Interface Project

A simple ATM simulation built using HTML, CSS, and JavaScript.

## Features

- Balance Inquiry
- Cash Withdrawal
- Cash Deposit
- Interactive User Interface
- Transaction Validation

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Use the ATM interface.
